このフォルダに以下のファイル名で画像を置くと、サイトに反映されます。

【会社ロゴ】
ファイル名: logo.png（または logo.jpg）
※ 拡張子を変える場合は index.html 内の "images/logo.png" の部分も合わせて変更してください。
置いていない間は、自動的に「心」の丸アイコン＋会社名（テキスト）が表示されます。

【ヒーロー画像（トップの背景写真）】
ファイル名: hero.jpg
推奨サイズ: 横1920px 以上（横長の写真）
置いていない間は、代わりに濃紺〜赤のグラデーション背景が表示されます。

画像を置いたら、index.html と images フォルダをまとめてNetlifyにアップロードしてください。
